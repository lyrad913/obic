## 대회 개요

태양광 발전소 운영에 있어 환경센서 활용은 발전 효율을 높이고 안정성을 확보하기 위한 핵심 요소입니다. 환경센서는 모듈 온도와 일사량을 비롯한 주변 환경 정보를 측정하는 장치로, 특히 일사량은 태양광 발전량과 가장 밀접한 기상 인자이며, 모듈 온도는 패널 효율에 직접적인 영향을 미칩니다.

그러나 H에너지와 같이 다수의 소규모 발전소를 운영하는 기업 입장에서는 모든 발전소에 환경센서를 설치하는 것이 비용 측면에서 현실적으로 어렵습니다.

이번 대회는 이러한 문제를 해결하기 위해 기획되었습니다.
국내 전역에 산재한 발전소 중 환경센서가 설치된 발전소의 데이터를 활용해, 센서가 없는 발전소의 일사량을 정밀하게 추정하는 것이 참가자들의 과제입니다.

정확한 일사량 추정치는 발전량 데이터와 비교되어 발전 효율 저하 감지, 원격 제어 시스템 고도화 등 다양한 분야에서 활용될 수 있으며, 향후 스마트 태양광 관리 체계의 핵심 기반이 될 것입니다.

> 환경센서 미설치 발전소의 일사량을 정밀하게 추정하는 모델 개발

## 제공 데이터

본 경진대회에서는 전국에 산재된 여러 발전소에서 2024년 8월 1일 00시부터 2025년 8월 1일 00시까지 수집된 1년치 데이터를 제공합니다. 제공되는 데이터는 모든 발전소에서 공통적으로 수집되는 데이터와, 환경센서가 설치된 발전소에서 추가적으로 수집되는 데이터로 구분됩니다.

1. 공통 데이터
   - 발전소 위치 정보
   - 발전소에 가장 인접한 기상 관측소의 실측 데이터(1시간 단위 제공)
2. 환경센서 설치 발전소
    - 환경센서에서 수집된 일사량 데이터(5분 단위 제공)
    - 태양광 발전량 데이터(15분 단위 제공)

### 유의사항
1. 태양광 발전량 데이터는 참고용으로 제공되는 것이며, 일반적으로 일사량 추정 시에 입력 변수로 사용하지 않습니다.
2. 제공되는 데이터셋은 수집 주기가 다른 여러 데이터를 취합하여 하나의 테이블 형태로 구성하였습니다. 수집 주기의 차이로 인해 일부 시간 구간에는 결측치(빈값)가 존재합니다. 결측치 처리 방법(보간, 대체 등)을 자유롭게 선택하여 모델을 개발해 주시기 바랍니다.
3. 제공드리는 데이터는 용량이 크기 때문에 pandas 패키지와 같은 데이터툴을 이용하여 열람해야 합니다.

### Dataset 정보

#### train.csv
환경센서가 설치된 발전소의 데이터. 총 33개의 컬럼

- 'time': 시간
- 'pv_id': 고유 발전소 ID
- 'appr_temp': 체감 온도. 실제 온도와는 다르게 인간이 느끼는 온도를 표현하는 값 (주로 바람과 기온만을 고려) (°C)
- 'ceiling': 천장고, 지상에서부터 첫 번째 구름층의 높이를 나타냄 (m)
- 'cloud_b': 기상관측소 b의 구름량. 하늘을 덮고 있는 구름의 비율 (%)
- 'dew_point': 이슬점. 공기가 포화되어 물방울이 형성되기 시작하는 온도 (°C)
- 'precip_1h': 지난 1시간 동안 기록된 강수량 (mm)
- 'pressure': 기압, 대기압을 나타냄 (hPa)
- 'real_feel_temp': 체감 온도. 바람, 습도 등의 기상 조건을 반영한 체감 온도 (°C)
- 'real_feel_temp_shade': 그늘에서의 체감 온도, 그늘에서 느껴지는 체감 온도로, 햇빛의 영향을 배제한 온도 (°C)
- 'rel_hum': 상대습도. 공기 중의 수증기 함량을 백분율로 나타낸 값 (대기 중 수증기의 비율) (%)
- 'temp_b': 기상관측소 b의 온도. 대기 중의 실제 온도 (°C)
- 'uv_idx': 자외선 지수. 태양의 자외선 강도를 나타내는 지수 (-)
- 'vis': 가시거리. 대기 중에 물체가 눈으로 보이는 최대 거리 (km)
- 'wind_chill_temp': 풍속냉각온도, 바람에 의해 체감되는 온도 (°C)
- 'wind_dir_b': 기상관측소 b의 풍향, 바람이 불어오는 방향 (°)
- 'wind_gust_spd': 돌풍. 특정 시간 동안 기록된 최고 순간 바람 속도를 나타냄 (km/h)
- 'wind_spd_b': 풍속, 바람의 속도 (km/h)
- 'cloud_a': 기상관측소 a의 구름량. 하늘을 덮고 있는 구름의 비율 (%)
- 'ground_press': 기압, 지면에서 측정한 대기압 (hPa)
- 'humidity': 습도. 공기 중의 수증기 함량을 백분율로 나타냄 (%)
- 'rain': 강우량. 일정 시간 동안 내린 비의 양 (mm)
- 'snow': 강설량. 일정 시간 동안 내린 눈의 양 (mm)
- 'temp_a': 기상관측소 a의 온도. 대기 중의 실제 온도 (°C)
- 'temp_max': 최고 온도, 해당 시간대의 최고 기온 (°C)
- 'temp_min': 최저 온도. 해당 시간대의 최저 기온 (°C)
- 'wind_dir_a': 기상관측소 a의 풍향, 바람이 불어오는 방향 (°)
- 'wind_spd_a': 기상관측소 a의 풍속, 특정 시간 동안 기록된 바람 속도를 나타냄 (km/h)
- 'coord1': 위치 좌표 1 (-)
- 'coord2': 위치 좌표 2 (-)
- 'type': 데이터 구분 (train/test)
- 'energy': 발전량 (kWh)
- 'nins': 일사량 (W/m2)

#### test.csv

환경센서가 설치되지 않은 발전소의 데이터로, 일사량을 추정해야 할 데이터입니다.

- 'time': 시간

데이터 불러오기 및 라이브러리 import

```python
import pandas as pd
from lightgbm import LGBMRegressor

train = pd.read_csv('train.csv')
test = pd.read_csv('test.csv')
submission = pd.read_csv('submission_sample.csv')
```

'time' 컬럼을 날짜/시간(datetime) 형식으로 변환

```python
train['time'] = pd.to_datetime(train['time'])
test['time'] = pd.to_datetime(test['time'])
```

데이터 수집 주기의 차이로 인한 결측치를 backward fill 방법으로 보간

예) 1:05, 1:10, ... , 1:55의 값은 2:00의 값으로 채우기
```python
features = train.columns.drop(['time', 'pv_id', 'type', 'energy', 'nins'])

dfs = []
for pv_id, df_group in train.groupby('pv_id'):
    dfs.append(df_group[features].apply(lambda x: x.fillna(method='bfill')))
weather_fillna_df = pd.concat(dfs)
train[features] = weather_fillna_df

dfs = []
for pv_id, df_group in test.groupby('pv_id'):
    dfs.append(df_group[features].apply(lambda x: x.fillna(method='bfill')))
weather_fillna_df = pd.concat(dfs)
test[features] = weather_fillna_df
```

결측치가 포함된 행 제거

```python
train = train.dropna(subset=features)
```


LightGBM 회귀 모델을 학습하고 test 데이터에 대해 일사량 추정값을 산출하는 과정

```python
lgbm = LGBMRegressor()
lgbm.fit(train[features], train['nins'])
lgbm_pred = lgbm.predict(test[features])
```

음수로 예측된 값은 0으로 치환

```python
lgbm_pred[lgbm_pred < 0] = 0
```

추정 결과를 제출 양식에 입력 및 저장하여 제출용 파일 생성

```python
submission['nins'] = lgbm_pred
submission.to_csv('result_submssion.csv')
```
